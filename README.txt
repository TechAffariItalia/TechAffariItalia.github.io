TECH AFFARI ITALIA — MINI APP TELEGRAM (VERSIONE 1)

CONTENUTO
- index.html
- styles.css
- app.js
- assets/logo.png
- assets/*.svg (immagini demo prodotti)

COSA FUNZIONA GIÀ
- Catalogo responsive per smartphone
- Ricerca prodotti
- Filtri per categoria
- Carrello con quantità e totale
- Salvataggio carrello sul dispositivo
- Checkout con dati cliente
- Integrazione Telegram WebApp
- Invio ordine via Telegram.WebApp.sendData quando la Mini App viene aperta da Telegram

IMPORTANTE
Questa è una versione dimostrativa. I prodotti, prezzi, disponibilità, caratteristiche, condizioni di vendita,
privacy, resi, spedizioni e pagamenti devono essere sostituiti/configurati con dati reali prima di vendere.

PASSO SUCCESSIVO
Pubblicare questi file su un hosting HTTPS gratuito (per esempio GitHub Pages / Cloudflare Pages / Netlify),
ottenere l'URL pubblico e collegarlo a @TechAffariItaliaBot tramite BotFather.
Successivamente sarà necessario collegare il bot a un backend/webhook per registrare gli ordini in modo affidabile.
